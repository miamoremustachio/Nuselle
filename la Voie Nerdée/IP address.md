
An *IP address* is a unique identifier assigned to each device connected to a computer network that uses the [[IP|Internet Protocol]] for communication.

It presents a sequence of characters which can reveals the user's approximate geographical location and identify their Internet Service Provider ([[ISP]])

## 📡 IP Standards

### IPv4

- The older, 32-bit standard
- Supports about 4 billion addresses
- Uses decimal dot-separated notation (e.g. `192.168.1.1`)

### IPv6

- The newer, 128-bit standard
- Has built-in security features like IPsec, data authentication and [[encryption]]
- Provides an almost unlimited addresses space (about 3.4×10<sup>38</sup>)
- Uses hexadecimal colon-separated notation (e.g. `2001:db8::1`)

## 🔗 Assignment types

### Static IP

- Permanently assigned to a device
- Reliable for servers and other devices that require constant address for regular access

### Dynamic IP

- Temporarily assigned from a pool of available addresses by the Dynamic Host Configuration Protocol ([[DHCP]])
- Efficient for providers and consumer devices that do not require permanent addresses
